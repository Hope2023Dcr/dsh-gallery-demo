# 产出台（dsh-gallery）· 功能演示

一个零依赖的单文件交互演示页，展示 DSH 插件「产出台」的全部核心能力。点开网页即可逐章点击交互，也可一键自动播放（带字幕讲解）。

## 本地预览

直接用浏览器打开 `index.html` 即可，无需安装任何依赖、无需联网。

## 发布到 GitHub Pages

1. 新建一个公开仓库（例如 `dsh-gallery-demo`）。
2. 把本目录下的 `index.html`、`.nojekyll`、`README.md` 三个文件上传到仓库根目录。
3. 进入仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
4. 等待 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> `.nojekyll` 用于关闭 Jekyll 处理，确保页面原样发布；请勿删除。

## 页面内容（8 章）

| 章 | 功能 | 一句话说明 |
|---|---|---|
| 1 | 概览 | 把 Agent 产出目录变成实时画廊，生成即可见、当场校验 |
| 2 | 实时画廊 | 图片/文件/音视频分栏，新产出触发增量刷新；按对话分组，可跳回对话 |
| 3 | 放大查看 | 以光标为中心缩放，批注贴着图面走 |
| 4 | 框选遮罩 | 矩形批注 / 反馈篮 / 右键生成遮罩，涂抹只留外轮廓 |
| 5 | 前后对比 | 滑块分割 + 平铺并排，放大锁定同一处，智能推荐排序 |
| 6 | 复制与写框 | 卡面复制文件到剪贴板；写进输入框只写草稿不发送 |
| 7 | 音视频 | 面板内播放、截帧入库（毫秒级命名）、选段裁剪 |
| 8 | 判断回环 | 标签是状态、反馈是指令；新终稿高亮 + 批示回流，零自动发送 |
