功能目录

把 Agent 的黑箱，变成看得见的画廊

DeepSeek Harness（DSH）插件「产出台」——盯住 Agent 真正写文件的产出目录，做成一个新产出即触发刷新的右侧栏画廊。生成即可见、当场能校验、就地可处置，不用等任务跑完才发现做错。

⚠ 没有它：任务跑完才知道结果

Agent 埋头出 30 张图，你全程看不到。等它念一串路径，才发现第 3 张风格就跑偏了，30 张全废。返工成本是「一次性验证」的好几倍。

✓ 有了它：过程中就能看见、喊停

新产出立即触发增量刷新，图片、文件、音视频约等于实时更新。不顺眼当场改标签、圈批注、生成 ComfyUI 遮罩——所有判断留在侧栏里完成。

实时画廊 · 三类资产一栏看全

图片、文档、音视频分栏陈列；全局资产按对话分组折叠陈列——点对话标题展开，该对话资产跟着显示；点资产上的「↗ 打开对话」直接回到它所属的那条对话。

  • ◎
    生成即可见：Host 盯住产出目录，一有新文件立即增量刷新（约 1 秒内）；看大图时自动暂停，不打断。
  • ▤
    只筛选不隐藏：定稿过程稿素材未归类 四个色块可点，点一下隐藏该类、再点恢复。
  • ⇄
    全局资产 · 对话分组：全局资产把产出按对话分组，每组带时间和「成稿 / 过程稿 / 素材」数量；点 ▼ 标题展开，该对话的资产就列在下面。当前对话＝只显示本对话真正产出的（含脚本生成、子智能体产出、同目录素材）。
  • ↗
    从资产打开对话：全局资产里每张卡都带「↗ 打开对话」按钮，点一下就跳回那条对话、自动展开分组——看到好东西不用再去列表里翻。
  • ▦
    三类分开：图片 200px 缩略图懒加载；文件支持 49 种格式；音视频独立第三栏、首帧缩略图。每栏每页 60 条。

放大查看 · 批注跟着图走

滚轮以光标为中心缩放（最大 8×），标注态按住鼠标中键平移；已画的框贴着图面走，不脱框、不漂到留白。

  • ⊕
    光标定点缩放：放大后仍盯着同一处细节，不是画面中心。
  • ✥
    中键平移：标注态左键留给画框，按住中键拖动移图，已画框跟着一起走。
  • ▣
    批注跟随：缩放、平移后框仍落在原图同一处；放大后 1:1 也不会飘到白边。
  • ⌨
    键盘全可用：↑↓平移 ←→切图 + -缩放 0复位 O切原图 Esc退出。

3

框选批注 → ComfyUI 遮罩

三种圈法各司其职：左键拖＝矩形批注，左键逐点＝标记进反馈篮，右键＝生成填充遮罩。涂抹只描区域外轮廓，内部交叉笔迹不计入。

  • ▭
    左键拖矩形：可写说明，批注列表里点「导出遮罩」生成 RGBA PNG。
  • ··
    左键逐点圈＝区域标记，闭合后进反馈篮，不生成任何文件。
  • ✎
    右键逐点 / 按住涂抹＝实心多边形遮罩，闭合即导出。顶点 4–20 个，可拖微调、Backspace撤点、Enter闭合。
  • ⬡
    只描外轮廓（v1.4.0）：涂抹的自交笔迹，松手后只保留整体边界，不再显示内部交叉线——看到的形状就是导出的遮罩。
  • ◧
    遮罩契约：选区内 alpha=0、区外 255，RGB 逐像素保留原图，ComfyUI 直接能用。另出红/绿/蓝填充图仅供目视核对。

前后对比 · 局部重绘一眼看差别

批量选两张即可进对比，候选里带遮罩关系的排最前。默认滑块分割，可切平铺并排；放大时两张锁在同一处、分割线留在屏幕上。

  • ⇄
    两种模式：T 切滑块 / 平铺。滑块左「前」右「后」，拖中间分割线。
  • ✦
    智能推荐：有遮罩关系 ＋1000 ＞ 同尺寸 ＋500 ＞ 时间更晚 ＋120 ＞ 同名主干 ＋80，最多 12 个候选。
  • ⊞
    平铺同步：左右各一格，共用缩放平移；滚轮以光标所在的那一格中心为不动点，两格同步。
  • ⌨
    专用键：← →微调分割线、X对调左右、Esc先退对比（不关大图）。

复制文件 · 写进输入框

卡面上的两个快捷按钮：复制文件本体到系统剪贴板（Ctrl+V 可粘出文件），或把「文件名＋路径＋遮罩」写进对话草稿——只写不发。

  • ⧉
    复制文件：文件卡片第二个按钮、图片卡片右上角 ⧉ 图标，都把文件本体写进系统剪贴板。在 WorkBuddy / 微信输入框按 Ctrl+V 直接粘出文件。
  • 📝
    写进输入框：文件卡片第一个按钮（原「预览」），把文件名＋绝对路径＋主遮罩写进草稿；点整张卡片或 Enter 仍是侧栏预览。
  • ⊕
    粘贴入库：鼠标停在资产区按 Ctrl+V，图片/文件都收，落在指针所在的对话组、自动标「素材」，原件不动。
  • ⊘
    红线：全程只复制、只写草稿，不移动、不自动发送。拖到外部应用传文件机制上走不通，统一用「复制 → Ctrl+V」。

音视频 · 截帧与选段裁剪

面板内直接播放、进度条任意拖动；「截取当前帧」自动入库、文件名精确到毫秒；「选段」拖入点出点，ffmpeg 切段落源目录。

  • ▶
    面板内播放：原生 video/audio，走 blob 整包载入，进度条可任意拖。实测 127 MB 视频 502 ms 打开、正常 seek。
  • 📷
    截帧入库：点「截取当前帧」，PNG 自动存进当前对话（不再弹保存框），文件名如 片子_帧_00-12-34-500.png，可直接框选批注进反馈篮。
  • ✂
    选段裁剪：拖入点/出点，播放自动从入点起、到出点停；默认流拷贝近无损，偏差 >0.5s 自动重编码到精确切点。
  • ◫
    格式兜底：浏览器解不了的格式，给「用系统播放器打开 / 打开所在文件夹」两个按钮。

7

判断与回环 · 让结果自己回来

判断只分两层：标签是状态（改过一直生效），反馈才是指令（人工审核后手动发送）。Agent 改完，新终稿高亮、批示回流，你核准才闭环。

1
改标签 / 圈批注 → 进反馈篮

定稿改过程稿附调整方向；图上框选带区域百分比与原话。攒成一条条 Annotation，界面不显示条数、不催办。

2
生成草稿 → 你手动发送

有多条意见才打包成草稿写进输入框，逐条列出区域和原话。插件只写不发，发送永远由你点。

3
Agent 改完 → 新终稿高亮 + 批示回流

刚落盘的终稿用绿框和「新」角标高亮（最多 3 张）；Agent 调 gallery_reply 把「做了什么、请验收」写成批示，单独出现在反馈栏顶部。

4
你核准 / 驳回 → 闭环

核准＝认可这次改动；驳回＝清掉批示并写一条你的意见，Agent 下次取回的就是它。台面开着会低频自动检查批示。
